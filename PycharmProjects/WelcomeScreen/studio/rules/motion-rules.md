# MOTION RULES (60 FPS REMOTION STANDARDS)
1. **Framerate:** Prefer 60fps for UI/Motion Graphics, 30fps for heavy paper-cutout layers.
2. **Pacing:** Never hold a static shot for more than 3.5 seconds. Always maintain gentle parallax, floating particles, or micro-breathing.
3. **Typography:** Pair clean geometric sans-serif with expressive editorial serif italics for emotional emphasis.
4. **Colors:** Deep matte backgrounds (`#08080c`), soft cotton paper (`#fdfbf7`), never use harsh neon unless intentionally glitching.
